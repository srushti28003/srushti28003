**[Soil-moisture forecasting and storage screening](https://github.com/srushti28003/soil-moisture-forecasting-storage)** · new research

**[AI for stormwater harvesting in agriculture](https://github.com/srushti28003/ai-stormwater-harvesting)** · MSc dissertation
A multi-model Python prototype (LSTM, Random Forest, classifiers) for storm risk, irrigation need and crop recommendations.
